# Calculadora de IMC (Índice de Masa Corporal)

Una aplicación web sencilla e interactiva desarrollada con HTML, CSS y JavaScript que calcula el Índice de Masa Corporal (IMC) a partir del peso y la altura ingresados por el usuario, mostrando la categoría correspondiente y una imagen ilustrativa.

---

##  Características

- **Cálculo en tiempo real:** Procesa los datos ingresados al hacer clic en el botón.
- **Conversión automática:** Convierte la altura introducida en centímetros a metros.
- **Categorización dinámica:** Clasifica el resultado en 4 rangos estándar de IMC:
  - **Bajo peso / Infrapeso:** IMC < 18.5
  - **Peso normal:** IMC entre 18.5 y 24.9
  - **Sobrepeso:** IMC entre 25.0 y 29.9
  - **Obesidad:** IMC ≥ 30.0
- **Feedback visual:** Muestra el valor numérico (redondeado a un decimal) junto a una imagen representativa para cada estado.

---

## Tecnologías utilizadas

- **HTML5:** Estructura de la página web e inputs de formulario.
- **CSS3:** Estilos básicos (color de fondo de la aplicación).
- **JavaScript (Vanilla):** Lógica del cálculo del IMC y manipulación del DOM.

---

## Requisitos e imágenes

Para que la aplicación muestre las imágenes correctamente, asegúrate de colocar los siguientes archivos en la misma carpeta que el archivo `index.html`:

- `infrapeso.webp`
- `normal.webp`
- `sobrepeso.webp`
- `obesidad.webp`
